## Agent skills

### Issue tracker

Issues and specs live as GitHub issues in ceragon/dragon18. See `docs/agents/issue-tracker.md`.

### Triage labels

Five default roles (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`), each label string equal to its name. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one root `GLOSSARY.md` and ADRs in `docs/adr/`. See `docs/agents/domain.md`.
